Voxel World Pixel — Deploy

OWNER-ONLY · BNB CHAIN

Owner-only page. Deploy the Voxel World Pixel NFT contract on BNB Chain, set the metadata base URI, verify Binance Agent ID wallets, open mint when ready, and withdraw the mint fees. Nothing here deploys or moves funds without your wallet confirmation.

01 Connect walletNot connected

Connect the wallet that should own the contract. It deploys the contract, is the only wallet that can open mint, set the base URI, verify Agent ID wallets or withdraw, and receives the mint fees on withdraw.

02 Deploy Voxel World PixelNot deployed

The collection rules are fixed in the contract and cannot be changed:

  • Supply: 1,111 — 1,000 Free Mint + 111 Genesis Mint. Each mint draws a random character; the minter cannot pick.
  • Free Mint: 0 BNB, max 4 per wallet, verified Binance Agent ID holders only, Common & Rare characters only (no Legendary).
  • Genesis Mint: 0.0015 BNB, max 5 per wallet, open to any wallet, full pool including Legendary.
  • Evolve: burn 2 Voxels + 0.001 BNB for 1 Evolved Voxel, at least 1 rarity tier higher (Legendary stays Legendary; Free-origin Evolves cap at Epic).
  • Fees stay in the contract until the owner withdraws them.
  • Mint starts CLOSED. Open it in step 03 when the web and metadata hosting are ready.
Set the base URI right after deploy (recommended — tokenURI points at the hosted metadata folder; while it is empty, tokenURI returns only the file name).
